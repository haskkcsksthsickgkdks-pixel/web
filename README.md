## 🚀 วิธีเปิดใช้งาน

### 1. เปิดเว็บเซิร์ฟเวอร์
```bash
npm start
```
เปิดเบราว์เซอร์ไปที่:
- **หน้าหลัก (Home)**: `http://localhost:3000/`
- **หน้ารายชื่อสมาชิก (Members)**: `http://localhost:3000/members.html`
- **หน้าผู้ดูแลระบบ (Admin)**: `http://localhost:3000/admin.html` (PIN: `admin344s` หรือ `168`)

### 2. วิธีเชื่อมต่อ Discord Bot
1. นำ Token และ Client ID มาใส่ในไฟล์ `.env`:
   ```ini
   DISCORD_TOKEN=โทเคนบอทของคุณ
   CLIENT_ID=Application_ID_ของบอท
   GUILD_ID=Server_ID_ดิสคอร์ดของคุณ
   ```
2. ลงทะเบียนคำสั่ง Slash Commands:
   ```bash
   npm run deploy-commands
   ```
3. เปิดบอท:
   ```bash
   npm run bot
   ```
4. ในห้องดิสคอร์ด พิมพ์คำสั่ง:
   ```
   /panel
   ```
   **บอทจะส่งแผงควบคุมพร้อมปุ่มกดแบบในรูป สามารถกดปุ่มเพื่อกรอกฟอร์มได้ทันทีครับ!**
